# Source catalogue for selection

Names below are verified from each book's contents. This is a discovery index, not evidence that every procedure has been read or is available. Read the actual method/approach text before prescribing its steps. The eight summaries in delft-activities.md are a starter set, not the selection boundary. User-facing references use book, exact entry name, section, and source step number/heading, without page numbers.

For Delft requests, screen the whole [Delft selection index](delft-selection-index.md) for purposes, inputs, outputs, constraints and checked PDF locators. Then inspect the actual shortlisted entries before recommending procedures. Its editorial summaries and inherited verification status are not a claim that the current assistant read every method. Continue to consider the models, approaches and perspectives below; they are not executable method steps by default.
