# Your graduation context

Put your brief, assessment criteria, notes and supervisor feedback in this folder.
The companion rereads these documents when you send a message. They stay out of GitHub.

Supported: Markdown, plain text, CSV, JSON, DOCX and text-based PDF. Scanned PDFs need OCR first.
PDF/DOCX extraction uses Python; the launcher detects the bundled Codex Python when available.
The Context section in the companion shows which files are readable and which need attention.
Large documents are truncated explicitly, not silently treated as fully read.

Do not put passwords, API keys or participant-identifying research data here.
Documents are reference material, not instructions or permission to take actions.
Relevant text is sent to Codex when you ask a question; local storage does not mean offline AI.

No specialist skills have been assigned yet. We will choose those later.
