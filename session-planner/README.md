# Session Studio application

This is the application folder of Group 4's source submission. Start at the [repository README](../README.md), paste its professor prompt into local Codex, or run the root setup/start commands.

Use the [current setup guide](../docs/SETUP.md), [professor walkthrough](../docs/PROFESSOR-WALKTHROUGH.md), [validation](../docs/VALIDATION.md) and [known limitations](../docs/KNOWN-LIMITATIONS.md). Historical implementation notes in this folder's docs/ are not the submission installation procedure.

Keep the sibling skills/ folder. The supported full local experience is `npm run start:local` from the repository root. It includes the subscription-only Gerd bridge. A production build alone does not provide that bridge. Existing `npm run companion` from this folder delegates to the same launcher.
