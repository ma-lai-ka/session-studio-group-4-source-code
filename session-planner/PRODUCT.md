# Current product scope

Sam's homepage opens browser-local projects. Sessions use a rule-based planner with source-backed methods and clearly labelled estimates. Users can edit budgets, search/filter methods, move blocks, review dependencies and record session outcomes. Completed sessions are retained. Method stages may be scheduled manually across sessions; the rule-based generator does not interpret project notes or evidence and does not automatically plan external research.

Projects are not synchronized between teammates or devices. JSON export/import supplies portable copies and backups. Existing browser drafts can be imported without removing their original copy. Storage failures and stale tabs are shown explicitly.

Existing Sites invitations control access. The existing catalogue metadata database remains. No new account configuration, model API, shared project database, upload bucket or external canvas integration is included. The team's replacement canvas remains future work until its interface is available.
